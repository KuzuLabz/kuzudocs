An ultra-fast React Native port of Vibrato, a Viterbi-based accelerated Japanese morphological analyzer and tokenizer written in Rust.

[Vibrato](https://github.com/daac-tools/vibrato) is brought to React Native via [Nitro Modules](https://nitro.margelo.com/).

## Install

```bash tab="npm"
npm install @kuzulabz/react-native-nitro-vibrato react-native-nitro-modules
```

```bash tab="pnpm"
pnpm add @kuzulabz/react-native-nitro-vibrato react-native-nitro-modules
```

```bash tab="yarn"
yarn add @kuzulabz/react-native-nitro-vibrato react-native-nitro-modules
```

```bash tab="bun"
bun add @kuzulabz/react-native-nitro-vibrato react-native-nitro-modules
```

## Usage
<Steps>
<Step>
### Initialize
```ts
import { initWasmAsync, Vibrato, MecabPreset } from '@kuzulabz/react-native-nitro-vibrato';

// Required for web! (safe to call on mobile)
await initWasmAsync();

// Minimal
const path = 'file://.../system.dic';
await Vibrato.initialize(path);

// With user dictionary
const userDict = 'file://.../user-dict.csv';
await Vibrato.initialize(path, userDict);

// With the Mecab Preset. 
// This will return the same token results as Mecab.
await Vibrato.initialize(path, userDict, MecabPreset);

// With multiple files
await Vibrato.initializeFromTextDic({
    char: 'file://.../char.def',
    lex: 'file://.../lex.csv',
    matrix: 'file://.../matrix.def',
    unk: 'file://.../unk.def'
});
```
</Step>
<Step>
### Tokenize
```ts
import { Vibrato, Token } from '@kuzulabz/react-native-nitro-vibrato';

// Returns tokens, each containing the surface, features, word cost, etc
const result: Token[] = Vibrato.tokenize(text);
```
</Step>
</Steps>

## API Reference
### Setup
#### initialize
Initializes Vibrato by loading the dictionary and creating a tokenizer.

```ts
await Vibrato.initialize("file://...");
```

#### destroy
Unloads the dictionary and destroys the tagger. Useful for changing dictionary or loading new user dictionaries.
```ts
Vibrato.destroy();
```

### Core
#### tokenize
Tokenize a japanese sentence.
```ts
const tokens = Vibrato.tokenize("すもももももももものうち");
tokens[0].surface
```

#### wakati
Segments/splits the japanese text by word. This is a `tokenize` wrapper and only returns the surfaces.
```ts
const words = Vibrato.wakati("すもももももももものうち");
```

### Hooks
#### useVibratoInitialized
Returns the initialization status of the dictionary / tokenizer. 

```ts
import { useVibratoInitialized } from '@kuzulabz/react-native-nitro-vibrato';

const isInit = useVibratoInitialized();

```

You can also get the initialization status manually by subscribing.

```ts
const [isInit, setIsInit] = useState(Vibrato.isInitialized);

const unsubscribe = Vibrato.subscribe(setIsInit);
```

### Constants
#### isInitialized
Returns the initialization status

## ZSTD Support
You can use .zst dictionaries by decompressing with [zstdify](https://github.com/bhouston/zstdify#readme).

### Example
```ts
import { Vibrato } from '@kuzulabz/react-native-nitro-vibrato';
import { decompress } from "zstdify";
import { File, Paths } from 'expo-file-system';

const compressedDic = new File(Paths.document, 'system.dic');
const systemDic = decompressDic(await compressedDic.arrayBuffer());
await Vibrato.initialize(systemDic);
```
